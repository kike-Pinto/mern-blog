# MERN Blog App

Full-stack blog application built with the MERN stack.

## Overview

This project includes a client and API architecture for a blog application. It was created to practice full-stack development, backend API design, database integration and frontend rendering.

## Features

- Blog frontend
- Backend API
- Client and server structure
- Database integration
- MERN stack architecture

## Tech stack

- MongoDB
- Express
- React
- Node.js
